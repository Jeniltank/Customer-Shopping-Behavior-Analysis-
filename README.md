## 📌 Project Overview

This project analyzes customer shopping behavior to uncover insights that help businesses make data-driven decisions. It covers the complete data analytics workflow—from data cleaning to visualization and insight generation.

---

## 🎯 Objectives

- Identify high-value customers  
- Analyze the impact of discounts on purchases  
- Understand age and gender-based buying behavior  
- Discover top-performing product categories  
- Identify key drivers of customer spending  

---

## 🧹 Data Cleaning & Preparation

- Removed duplicates and unnecessary columns  
- Handled missing values (mean, median, mode)  
- Converted data types for consistency  
- Created new features (age groups)  
- Standardized categories and labels  

---

## 🔎 Exploratory Data Analysis (EDA)

- Age distribution and segmentation  
- Gender-wise purchasing trends  
- Purchase amount comparison  
- Discount vs non-discount behavior  
- Category-level analysis  
- Outlier detection using box plots  

---

## 📊 Visualizations

- Histogram of purchase amounts  
- Customer demographic analysis  
- Category-wise sales charts  
- Gender vs purchase comparison  
- Discount impact analysis  
- Correlation heatmap  

---

## 🧠 Key Insights

- Customers using discounts tend to spend more  
- Young adults are the most active buyers  
- Female customers show slightly higher engagement  
- Top categories generate the majority of revenue  
- Higher discounts increase purchase value  
- Repeat customers spend more on average
